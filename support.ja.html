サポート

お困りのときは、まず下の回答をご覧ください。解決しない場合はメールでご連絡ください。ゲーム内の「設定」は画面右上の歯車のボタンで、タイトル画面とステージ中のどちらにもあります。

購入を復元するには？

「設定」を開き、「購入を復元」をタップしてください。「星図」で鍵のかかった星（小さな鍵のマークがついた星）をタップすると開く「完全版」のカードにも、同じボタンがあります。インターネットに接続し、購入したときと同じ Apple ID でサインインしていることをご確認ください。購入はお客様の Apple ID にひもづいており、当方には記録がありません。完全版が開放されると、設定に「完全版を解放済みです。応援ありがとう！」と表示されます。

支払ったのに、ステージが開放されません。

まず「購入を復元」をお試しください。カードに「承認を待っています」と表示されている場合（ファミリー共有の「承認と購入のリクエスト」など）は、購入が承認された時点でステージが開きます。返金は Apple が対応します：support.apple.com をご覧ください。

進み具合はどのように保存されますか？

端末に自動で保存されます（点灯させたステージとその星の数、毎日のパズルの結果と連続日数）。アカウントはなく、何もアップロードされません。ゲームを閉じても、アップデートしても進み具合は残ります。アプリをアンインストールすると削除されます。購入はセーブデータには含まれず、お客様の Apple ID にひもづいているので、いつでも復元できます。

新しいスマートフォンに引き継げますか？

購入は Apple ID と一緒に引き継がれます。新しい iPhone・iPad で同じ Apple ID でサインインし、ゲームをインストールして「購入を復元」をタップしてください。進み具合は元の端末にだけ保存されており、オンライン同期はありません。元の端末の iCloud またはコンピュータのバックアップから新しい端末をセットアップすると、通常は進み具合も引き継がれます。

言語を変えるには？

ゲームは、できるかぎり端末の言語で起動します。変えるときは「設定」を開いて「言語」をタップし、言語を選んでください。「端末の設定」を選ぶと、ふたたび端末の言語に合わせます。対応言語は 17 種類です：English、简体中文、繁體中文、日本語、한국어、Español、Português (Brasil)、Français、Deutsch、Italiano、Русский、Türkçe、Bahasa Indonesia、Tiếng Việt、ไทย、हिन्दी、العربية。

音が聞こえません。

「設定」を開き、「効果音」と「音楽」が「オン」になっているかご確認ください。スイッチをタップすると切り替わります。端末の音量と、iPhone の消音モードもご確認ください。

インターネット接続は必要ですか？

遊ぶだけなら必要ありません。すべてのステージと毎日のパズルはゲームに収録されています。価格の表示、完全版の購入、購入の復元には App Store への接続が必要です。購入後は端末がそれを覚えているので、オフラインでも遊び続けられます。
